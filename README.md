# Projeto_de_sistema_bancário
Fiz um programa de sistema Bancário
# Parte de validação

> Utilizei dicionários para guardar alguns dados como o nome do usuário, senha e o valor do saldo inicial.

> A parte da validação do nome do usuário optei por não determinar uma quantidade de número de tentativas, já na parte da senha o usuário tem um total de 4 tentativas para conseguir acessar a sua conta, senão o programa será encerrado.
